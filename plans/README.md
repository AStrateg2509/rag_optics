## Первичная настройка (один раз)

1. Создать репозиторий на GitHub, клонировать в WSL2.
2. Положить в корень `CLAUDE.md`, папки `plans/` и `docs/`. Закоммитить в `main`: `chore: ТЗ, планы и CLAUDE.md`.
3. Открыть папку в VS Code (Remote — WSL) и запустить Claude Code.

## Цикл одной лабы

1. `git switch main && git pull && git switch -c lrN-...`
2. Перевести Claude Code в режим планирования (Shift+Tab, пока не появится plan mode, или `claude --permission-mode plan`).
3. Вставить промпт **10.1** из нужного `lrN.md`. Перед этим выбрать, какие **[ОПЦИОНАЛЬНО]**-пункты делаем.
4. Прочитать предложенный план. Сверить его с разделами 4 и 6 файла `lrN.md`, при необходимости поправить. Затем одобрить.
5. Реализация. Попросить Claude Code коммитить после каждого крупного шага и прогонять `ruff` и `pytest`.
6. Пройти раздел 5 «Как проверить и показать» руками и отметить чек-лист раздела 6.
7. В обычном режиме — промпт **10.2**: Claude Code составляет `defense/lrN.md` (сценарий сдачи, теория, вопросы с ответами) и `defense/lrN-cheatsheet.md`.
8. Промпт **10.3**: Claude Code составляет отчёт `docs/reports/lrN.md` по шаблону. Закрыть его список TODO (скриншоты, ФИО преподавателя, номер PR).
9. Репетиция по разделу 1 `defense/lrN.md`: уложиться в 5–7 минут.
10. Создать PR `lrN-...` → `main`. В описание вставить чек-лист и шаги проверки. После проверки слить.

В ЛР5 дополнительно собираются материалы к зачёту: `defense/final.md` и `docs/reports/final.md`.

## Порядок и зависимости

ЛР1 → ЛР2 → ЛР3 → ЛР4 → ЛР5 → (ЛР6). Каждая лаба опирается на код предыдущих, поэтому её ветка создаётся от `main` после слияния прошлой.
